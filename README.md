GRANNIES HOME MULTI-PAGE WEBSITE
================================

Files:
- index.html       Home / split Senior Living + Youth Housing landing page
- seniors.html     Independent Senior Living
- foster-youth.html THP-NMD Youth Housing
- about.html       About Grannies Home
- programs.html    Programs overview
- contact.html     Contact page
- style.css        Responsive styling, animations, floating icon, image banners
- script.js        Mobile menu, scroll reveal, contact mailto form

HOW TO USE
1. Upload all files to the same folder on your hosting account.
2. Make sure index.html is in the public root (often public_html).
3. Your domain will automatically load index.html.
4. The navigation is already linked between the pages.

IMAGES
The website uses remote Unsplash image URLs so banners work immediately. You can replace those URLs in style.css / HTML with your own Grannies Home photos for a fully branded site.
